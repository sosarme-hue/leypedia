Cómo se mantiene actualizado

  1. Cada mañana se leen el BOE y el DOGC.
  2. Se detecta qué fichas afecta cada disposición nueva.
  3. Esas fichas se revisan y se actualizan con la versión consolidada.
  4. Cada ficha muestra la fecha de vigencia y la fuente con la que se comprobó.
