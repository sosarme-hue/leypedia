Contracte de lloguer de traster

Per llogar un traster independent per guardar-hi coses. Omple les dades i el document s'escriu sol, al teu navegador.

PreuGratuït
NormaCódigo Civil, articles 1542 i següents

Les teves dades no surten d'aquest navegador: no s'envien ni es desen.

Consells

  • Feu una llista del que s'hi guarda si té valor.
  • El propietari no respon dels objectes guardats llevat que es pacti.

A Catalunya

Les regles són les mateixes que a la resta d'Espanya.

Model orientatiu. Revisa'l amb un professional si el cas té particularitats.
